## Verification (for `verifier`)

### Changed-risk surface

This is where money actually changes hands, and it now also maintains a denormalized cache. Four
things to hunt for:
1. **Silent repricing of history** — an issued invoice whose displayed or stored total moves because
   something still recomputes instead of reading `billed_*`.
2. **The removed side effect** — anything still writing `appointments.price_override_cents` from the
   invoice path, or an appointment that should have kept its override losing it.
3. **Cache drift** — `appointments.billed_price_cents` disagreeing with its junction row, surviving
   removal from an invoice, or being written by a second code path. Section 3 of
   `pricing_backfill_check.sql` is the detector; run it after every smoke step.
4. **Rounding at the wrong level** — a total computed as `round(sum of unrounded amounts)` rather
   than `sum of rounded lines`.

### Smoke script

Against a reset + seeded local stack, signed in as the seeded admin. Seed data: `Standard House
Cleaning` @ $45.00/h, `Hourly Deep Clean` @ $60.00/h, and a $38.00/h client rule on `Hourly Deep
Clean` effective today.

1. Create appointment **A**: seeded client, `Hourly Deep Clean`, today, 09:00–11:30, no override.
   Detail page → `$95.00`, `Client rate`, `$38.00/h × 2h 30m`.
2. Create appointment **B**: same client, `Standard House Cleaning`, today, 13:00–15:00, no
   override. Detail page → `$90.00`, `Standard rate`, `$45.00/h × 2h 0m`.
3. Appointments list → A shows `$95.00`, B shows `$90.00`, neither chipped `Invoiced`.
4. Snapshot: `SELECT id, price_override_cents, billed_price_cents FROM appointments WHERE id IN (A,B);`
   → both `billed_price_cents` NULL.
5. New invoice for that client, select A and B, accept both default prices, save.
   - `SELECT total_cents FROM invoices WHERE id = I;` → `18500`
   - `SELECT appointment_id, billed_amount_cents, billed_rate_cents, billed_minutes
      FROM invoice_appointments WHERE invoice_id = I;` → `(A, 9500, 3800, 150)`, `(B, 9000, 4500, 120)`
   - `SELECT billed_price_cents FROM appointments WHERE id IN (A,B);` → `9500`, `9000`
   - `price_override_cents` for both → **identical to step 4's snapshot**
   - appointments list → both chipped `Invoiced`
6. Edit the draft, overtype A's line to `120.00`, save → `billed_amount_cents = 12000`,
