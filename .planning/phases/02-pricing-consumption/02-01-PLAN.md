# 02-01-PLAN — Jobs pricing surface

Two tasks, no shared writable file, both dispatchable the moment Phase 1 lands. They are split on
the action↔form seam; the field contract below is what lets them run at the same time.
Read `02-CONTEXT.md` first.

Revised 2026-09-18: ARCH-1 (D-09) removed the pricing-mode concept entirely, so this plan shrank —
there is no mode selector, no flat-price field, and no mode-switch clearing behaviour to build.

## Shared contract (both tasks build against this — do not renegotiate it)

`job-form.tsx` posts, and `parseJobFormData` in `jobs.ts` reads, exactly these fields:

| `name=` | Type | Notes |
|---|---|---|
| `name` | text | required, unchanged |
| `description` | textarea | unchanged |
| `hourly_rate_cents` | number, dollars | required; **renamed input**, was `base_price_cents` |
| `estimated_duration_minutes` | number, minutes | unchanged; scheduling only, never priced |

`JobActionResult`'s `fieldErrors` gains `hourly_rate_cents?: string` and loses
`base_price_cents?: string`. `estimated_duration_minutes?` stays. The form renders each error under
its own field exactly as it does today.

`JobFormProps['job']` becomes:
```ts
job?: {
  id: string
  name: string
  description: string | null
  hourly_rate_cents: number
  estimated_duration_minutes: number | null
}
```

  `@/lib/pricing/money`. The badge at ~84 renders `formatRate(job.hourly_rate_cents)` → `$45.00/h`.

**`jobs/page.tsx`** (both selects, active and archived) and **`jobs/[id]/edit/page.tsx`**: change

Before editing either route file, read

## Verification (for `verifier`)

### Changed-risk surface

Small. A field rename through a form, an action and two routes, plus the deletion of one inline
parser in favour of the shared one. The failure modes worth hunting: a form input whose `name` no
longer matches what the parser reads (silently writing nothing); a `.select()` string still naming
the old column (a runtime PostgREST 400, invisible to `tsc`); and a validation message that now
fires on a value that used to be accepted.
